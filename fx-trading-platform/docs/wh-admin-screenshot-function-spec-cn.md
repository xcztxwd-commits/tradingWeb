# WH 外汇后台截图功能说明文档

生成日期：2026-06-10

适用目标：按照用户提供的后台截图，拆解 `后台管理系统` 每个页面、按钮、表单、弹窗、表格、设置项和联动关系。本文只描述截图中可见或可从截图直接推断的功能，不代表当前本地系统已经全部实现。

## 1. 总体框架

### 1.1 页面骨架

- 顶部栏：左侧显示 Logo 和系统名 `后台管理系统`，中间显示面包屑，例如 `仪表盘 / 用户管理`，右侧显示全屏按钮、通知铃铛、用户头像，以及九宫格/应用入口图标。
- 左侧菜单：固定侧边栏，按一级菜单分组折叠。可见一级菜单包括 `首页`、`权限`、`产品管理`、`财务管理`、`用户管理`、`订单管理`、`验证码发送记录`、`请求日志`、`公告列表`、`新闻列表`、`系统设置`、`通知表`。
- 多标签栏：打开过的页面以标签形式横向排列，标签带关闭 `x`；当前标签为蓝底，非当前标签为浅灰底；标签过多时出现左右滚动箭头。
- 内容区：灰色背景，页面主体通常是白色工作区；列表页上半部分是搜索表单，下半部分是工具栏、表格和分页。
- 右侧固定操作列：多列表格横向溢出时，`操作` 列固定在右侧，带阴影分隔。
- 底部折叠按钮：左侧菜单底部有折叠菜单宽度的按钮。

### 1.2 全局按钮和控件语义

| 控件 | 功能 | 典型联动 |
| --- | --- | --- |
| `搜索` | 按当前搜索表单查询列表 | 请求列表接口，页码重置为第 1 页 |
| `重置` | 清空搜索条件 | 表单恢复初始值，并重新请求列表 |
| `新增` | 打开新增弹窗或抽屉 | 表单为空，提交后新增记录并刷新列表 |
| `删除` | 删除选中行或当前行 | 无选中时应提示；确认后删除并刷新列表 |
| `导入` | 打开文件导入 | 选择文件后上传，成功后刷新列表 |
| `导出` | 导出当前筛选结果 | 按当前搜索条件生成文件 |
| `展开/折叠` | 展开树表或树菜单 | 对部门、菜单、树权限生效 |
| `编辑` | 打开编辑弹窗或抽屉 | 表单带入当前行数据，保存后刷新 |
| `审核` | 打开审核弹窗 | 选择审核状态、填写备注，提交后改变订单状态 |
| `更多` | 展开更多行操作 | 用于承载低频动作，例如重置密码、登录、备注、发信 |
| 状态开关 | 启用/停用记录 | 通常立即请求状态更新接口 |
| `+ / -` 排序步进 | 调整排序数值 | 修改排序字段，可立即保存或延迟保存 |
| 表格刷新图标 | 重新加载表格 | 保持当前筛选和分页 |
| 表格搜索图标 | 显示/隐藏搜索区或表格查找 | 不修改数据 |
| 打印图标 | 打印当前表格 | 仅前端导出/打印视图 |
| 设置齿轮 | 打开表格设置 | 配置列宽、隐藏、固定、排序、本页/服务器排序 |

### 1.3 通用表格能力

- 行选择：每行左侧有 checkbox，表头 checkbox 用于全选当前页。
- 分页：显示总数、当前页、页码、下一页、每页条数选择、前往页输入框。
- 排序：部分列名旁有上下箭头，支持本页排序或服务器排序。
- 空数据：表格中间显示空状态图标和 `暂无数据`。
- 横向滚动：字段较多时底部有水平滚动条，右侧操作列固定。
- 表格设置弹窗：支持表格大小、边框显示方式、斑马纹、列宽、隐藏列、固定列、排序方式。

### 1.4 通用弹窗和抽屉

- 居中弹窗：用于用户编辑、角色编辑、数据权限、菜单权限、风控设置、充值审核、充值编辑等。
- 右侧抽屉：用于菜单编辑等字段较多但仍需保留列表上下文的表单。
- 弹窗底部按钮：通常是 `关闭/保存` 或 `取消/确定`。
- 遮罩层：打开弹窗时背景变暗，禁止直接操作列表。
- 必填字段：以红色 `*` 标识。
- 密码字段：带眼睛图标，可显示/隐藏密码。
- 上传区域：虚线边框、加号图标、字段名，例如 `头像`、`凭证`。
- 富文本编辑器：包含源码、撤销、重做、剪贴板、字体、加粗、斜体、下划线、删除线、链接、全屏、预览、对齐、列表、引用、上下标、表格、媒体、特殊符号等工具。

## 2. 首页与个人中心

### 2.1 仪表盘

可见模块：

- 欢迎区：头像、用户名 `fuhao123`、文案 `欢迎回来！`。
- 时间卡片：右侧蓝色卡片，显示当前时间和日期，例如 `03:15:05`、`2026年06月10日`。
- 统计卡片：
  - `用户 / 用户统计`：总数、新增。
  - `真实 / 真实用户`：总数、新增。
  - `体验 / 体验用户`：总数、新增。
  - `充值 / 充值订单统计`：总数、新增。
  - `提现 / 提现订单统计`：总数、新增。
  - `订单 / 订单统计`：总数、新增。
- 趋势图：下方折线图，横轴为日期，纵轴为数量或统计值。

最小功能点：

- 页面进入时加载管理员信息、统计数据、趋势数据。
- 时间卡片每秒刷新，不应触发后端请求。
- 统计卡片颜色区分模块：用户蓝、真实蓝、体验蓝、充值红、提现粉、订单绿。
- 新增数以红色向下或绿色向上箭头表示趋势。
- 趋势图支持空数据时仍显示网格和横轴日期。
- 点击统计卡片可扩展为跳转对应列表：用户列表、充值订单、提现订单、订单列表。

### 2.2 个人信息 - 个人资料

页面结构：

- 顶部个人背景图：浅蓝天空背景，中间圆形上传区，按钮文案 `本地上传`，下方显示用户名标签。
- 左侧卡片：`个人资料`、`安全设置` 两个页签。
- 右侧卡片：`登录日志`、`操作日志` 两个页签。

个人资料表单字段：

- `账户名`：只读或禁用，示例 `fuhao123`。
- `昵称`：可编辑。
- `手机`：可编辑。
- `邮箱`：可编辑。
- `个人签名`：textarea，右下角显示 `0/255` 字数。

按钮：

- `保存`：提交资料变更。
- `退出系统`：清理登录状态并跳转登录页。
- `本地上传`：上传头像或个人封面相关图片。

联动和校验：

- 头像上传成功后，顶部头像、右上角头像、个人资料头像应同步刷新。
- 昵称、手机、邮箱保存成功后，登录用户信息缓存应同步更新。
- 签名最大 255 字，超过应禁止输入或保存时报错。
- `退出系统` 应调用退出接口或至少清理本地 token，再关闭所有打开标签或跳转登录。

### 2.3 个人信息 - 安全设置

安全设置表单字段：

- `旧密码`：必填，密码输入框，带显示/隐藏按钮。
- `新密码`：必填，密码输入框，带显示/隐藏按钮。
- `密码安全`：密码强度条，至少三段。
- `确认密码`：必填，密码输入框，带显示/隐藏按钮。

按钮：

- `保存`：提交密码修改。

联动和校验：

- 新密码输入时实时计算强度。
- 确认密码必须与新密码一致。
- 修改成功后应提示重新登录或自动退出。
- 旧密码错误时仅提示错误，不清空全部表单。

### 2.4 登录日志

列表内容：

- 登录时间，例如 `2026-06-07 18:19:37`。
- 登录结果，例如 `登录成功`。
- 地理位置，例如 `马来西亚`。
- 操作系统，例如 `Windows 10`、`Mac`。

联动：

- `登录日志` 页签只展示当前管理员自己的登录记录。
- 时间线蓝点按时间倒序排列。
- 可扩展为分页或滚动加载。

### 2.5 操作日志

列表内容：

- 操作时间。
- 操作描述，例如 `执行了 后台登陆`、`执行了 充值审核`、`执行了 充值订单保存`。
- 地理位置。
- 请求方式，例如 `POST`。
- 路由，例如 `/system/member/ht_login`、`/system/memberRecharge/edit_status`。

联动：

- `操作日志` 页签切换时加载当前管理员操作日志。
- 和全局 `请求日志` 不同，这里聚焦当前账号。

## 3. 权限管理

### 3.1 权限 - 后台用户管理

搜索区：

- 部门树：左侧独立部门筛选卡片，包含 `搜索部门` 输入框、`折叠` 按钮、部门节点 `所有部门`、`组长`。
- `账户` 输入框。
- `手机` 输入框。
- `邮箱` 输入框。
- `状态` 下拉框。
- `注册时间` 日期范围。

工具栏：

- `新增`：新增后台管理员账号。
- `删除`：批量删除选中后台账号。
- `导入`：导入后台账号。
- `导出`：导出当前筛选账号。
- 表格工具：刷新、搜索、打印、设置。

表格列：

- 选择框。
- `头像`。
- `账户`。
- `昵称`。
- `手机`。
- `邮箱`。
- `状态`：蓝色开关。
- `注册时间`。
- `操作`：`编辑`、`删除`、`更多`。

后台用户编辑弹窗字段：

- `头像`：展示或上传。
- `账户`：必填，编辑时通常不可修改。
- `密码`：新增必填，编辑可为空表示不改密码。
- `角色`：必填，多选标签形式，例如 `1000`。
- `岗位`：下拉选择。
- `所属部门`：必填，多选或树选择。
- `昵称`。
- `手机`。
- `邮箱`。
- `状态`：单选 `正常`、`停用`。
- `备注`：textarea。

按钮：

- `关闭`：不保存。
- `保存`：提交新增或修改。

联动：

- 选择部门会影响用户所属组织、数据权限范围。
- 选择角色会影响用户可见菜单和按钮权限。
- 选择岗位可用于组织内职责标识，不直接等同角色权限。
- 修改状态为停用后，该后台账号应无法登录或请求后台接口。
- 删除后台账号时不能删除当前登录账号和超级管理员。

- 数据权限影响列表查询范围，例如只能查看本部门用户、订单、资金记录。

菜单编辑抽屉字段：

- `上级菜单`：下拉选择。
- `菜单名称`：必填。
- `菜单类型`：单选 `菜单`、`按钮`、`外链`、`iFrame`。

- `菜单类型=iFrame` 时应校验 iframe 地址并按安全策略限制。
- `生成按钮=是` 可自动生成常见按钮权限，例如新增、编辑、删除、导入、导出。
- 隐藏菜单不显示在侧边栏，但可被路由或按钮引用。

## 10. 功能验收口径

要宣称“百分百实现截图功能”，至少满足以下条件：

- 所有截图中的菜单都能在左侧菜单和多标签中打开。
- 每个列表页支持搜索、重置、分页、排序、行选择、刷新、表格设置。
- 每个 `新增/编辑/删除/审核/导入/导出/状态开关/排序步进` 都有后端接口、前端调用、权限控制、审计日志。
- 每个弹窗字段都有前端校验、后端校验和数据库字段来源。
- 充值、提现、交易、平仓、撤销等资金相关操作必须保证资金明细和余额一致。
- 角色菜单权限能控制菜单、路由和按钮。
- 角色数据权限能限制用户、订单、财务、日志等列表查询范围。
- 所有配置项能影响对应业务逻辑，而不只是保存文本。
- 所有上传字段遵守上传配置，并支持预览、删除、回显。
- 所有高风险操作保留操作日志、请求日志和操作人信息。
