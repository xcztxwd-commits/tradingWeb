# wh-admin 后台功能审计

审计目标：`https://wh-admin.lonbmau.vip/`

审计时间：2026-06-10（Asia/Kuala_Lumpur）

## 结论范围

- Chrome 已打开的登录态页面确认：当前标签为 `https://wh-admin.lonbmau.vip/#/dashboard`，标题为 `仪表盘 - 后台管理系统`。
- in-app Browser 无登录态访问会跳到 `/#/login?redirect=/dashboard`，说明后台完整功能依赖登录态和权限菜单。
- 前端是 Vite/Vue/MineAdmin/Arco 管理后台，入口资源为 `/assets/index-2c28fe40.js`。
- 生产配置里包含 `VITE_APP_BASE_URL=http://127.0.0.1:8002`、`VITE_APP_PROXY_PREFIX=/prod`。当前机器访问 `127.0.0.1:8002` 不通；访问 `https://wh-admin.lonbmau.vip/prod/system/getInfo` 返回 `401`，所以未读取 Chrome token，也未调用带登录态的写接口。
- Chrome DOM 深度自动化通道不稳定，已多次超时；因此二级菜单和页面功能主要来自前端静态 chunk、接口配置、权限码、字段配置解析。未实际点击提交新增、修改、删除、审核、导出等有副作用按钮。

## 全局功能

- 登录页：账户、密码、验证码、登录按钮、验证码切换。
- 顶栏：页面搜索、全屏/退出全屏、换肤、页面设置、语言、暗色模式、多标签、菜单折叠、菜单宽度、清除缓存、退出登录。
- 多标签：刷新、全屏、关闭当前、关闭左侧、关闭右侧、关闭其他。
- 通用表格 `MaCrud`：搜索、重置、表格刷新、右键菜单、打印表格、上下文新增/编辑/删除、行选择、分页、排序。
- 通用写操作：新增、编辑、删除、真实删除、恢复、回收站、导入、导出、状态切换；是否显示由 `system:*:*` 权限码控制。

## 写操作风险点

- `删除`、`真实删除`、`恢复`、`审核通过/拒绝`、`修改余额`、`重置密码`、`强制退出`、`后台登录`、`批量盈利/亏损/正常/下线` 都是高风险操作；应在生产环境二次确认权限和审计日志。
- 充值、提现审核通过/拒绝会影响资金流；产品风控/K线设置会影响行情表现；订单 `平仓/成交/撤销` 会影响交易结果。
- 会员 `后台登录` 会打开用户侧登录 URL，属于代入用户身份操作，需要明确授权。

## 未完全验证项

- 未读取 Chrome token、cookie、localStorage，也未提交任何写接口。
- 由于 Chrome 深度 DOM 自动化不稳定，未逐个菜单实际点击打开；菜单归属以当前可见菜单和前端 chunk/权限码推断。
- 后端动态菜单接口需要登录态；无凭证请求 `/prod/system/getInfo` 返回 `401`。
